# Contributing to Flutter Quiz Master

First off, thank you for considering contributing to this project! It's people like you that make open-source software such a great community.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/YOUR_USERNAME/quiz-1.git`
3. **Create a new branch** for your feature or bugfix: `git checkout -b feature/my-awesome-feature`
4. **Make your changes** and test them.
5. **Commit your changes**: `git commit -m "feat: add awesome feature"`
6. **Push to your fork**: `git push origin feature/my-awesome-feature`
7. **Submit a Pull Request** against the `main` branch.

## Code Style

- Please adhere to the standard Flutter/Dart formatting (`dart format .`).
- Ensure all tests pass before submitting a Pull Request.
- Follow the existing project structure and state management patterns (Provider).

## Reporting Bugs

If you find a bug, please create an issue providing as much information as possible:
- Steps to reproduce
- Expected behavior
- Actual behavior
- Device/OS and Flutter version

Thank you!
