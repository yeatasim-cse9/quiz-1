A highly interactive and beautifully designed Flutter Quiz Application featuring 3D confetti animations, real-time state management, and customizable quiz experiences.

## ✨ Features

- **Dynamic Categories:** Select from various diverse topics.
- **Customizable Quizzes:** Adjust the difficulty and number of questions to your liking.
- **Beautiful UI/UX:** Clean, modern, and engaging user interface.
- **Real-time Timer:** Built-in timer widget to keep the pressure on!
- **State Management:** Seamless experience powered by `Provider`.
- **Celebration Animations:** Immersive 3D physics-based confetti effects on successful completion.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Dart SDK
- Android Studio / VS Code

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yeatasim-cse9/quiz-1.git
   ```
2. Navigate to the project directory
   ```bash
   cd quiz-1
   ```
3. Install dependencies
   ```bash
   flutter pub get
   ```
4. Run the app
   ```bash
   flutter run
   ```

## 📂 Project Structure

```
lib/
├── models/         # Data classes and structures
├── providers/      # State management logic
├── screens/        # UI Screens (Quiz, Results, Config, etc.)
├── services/       # External APIs and local storage
├── theme/          # App-wide color palettes and themes
└── widgets/        # Reusable UI components (Confetti, Timer, etc.)
```
